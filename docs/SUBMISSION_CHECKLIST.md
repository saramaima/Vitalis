# Submission Checklist

Before handing in or demonstrating Vitalis:

- [ ] MySQL is running.
- [ ] Backend `.env` is configured locally (do not submit secrets).
- [ ] `composer install` completed.
- [ ] `php artisan migrate` completed.
- [ ] `php artisan serve` is running.
- [ ] `npm install` completed in the frontend.
- [ ] `npm run dev` / `npm.cmd run dev` is running.
- [ ] Register works.
- [ ] Onboarding works.
- [ ] Dashboard loads after onboarding.
- [ ] Manual food creation works; newly created food is selected automatically.
- [ ] Meals, water, weight and exercise can be added.
- [ ] Progress shows an empty-state message until weight data exists.
- [ ] Settings and logout work.
